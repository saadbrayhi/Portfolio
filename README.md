## Overview

This portfolio presents selected projects, technical capabilities, and development experience across backend, web, and mobile applications.

It is built as a lightweight static website for fast loading, responsive performance, simple maintenance, and reliable deployment.

## Featured Work

### SkillTrade

A full-stack skill-exchange platform with authentication, proposal management, premium access, user workflows, and a modern Next.js architecture.

### User Management Application

A full-stack CRUD system built with Angular, NestJS, PostgreSQL, TypeORM, and PrimeNG, including server-side pagination, sorting, filtering, search, and validation.

### Users Mobile App

An Ionic and Angular mobile client connected to the user-management API, with CRUD operations, search, sorting, pagination, validation, and Android support through Capacitor.

### Pathly

A study-abroad guidance platform built with Next.js and TypeScript to help students explore destinations, scholarships, admission requirements, documents, visas, and study paths.

### Task Management Application

A full-stack task management application using React, Node.js, Express, Prisma, and PostgreSQL.

## Deployment

The portfolio is deployed with **Cloudflare Pages** and connected directly to the GitHub repository.

```text
GitHub main branch
        ↓
Cloudflare Pages
        ↓
Automatic production deployment
```

Every push to `main` automatically triggers a new production deployment.

## Local Development

Clone the repository:

```bash
git clone https://github.com/saadbrayhi/Portfolio.git
cd Portfolio
```

Open `index.html` directly in your browser or use VS Code Live Server.
